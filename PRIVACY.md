# プライバシーポリシー（video-studio rclone）

最終更新：2026-10-08

1. このアプリは、持ち主本人が自分の Google ドライブのファイルを、自分の Mac と自分のクラウドの作業環境との間でコピーするためだけに使います。一般の利用者はいません。
2. 読み書きするのは、アクセスを許可した Google アカウントのドライブのファイルだけです。
3. 受け取ったデータを第三者に渡したり、売ったり、広告に使ったりしません。保存するのは、本人の Mac と本人のクラウドの作業環境の中だけです。
4. Google API から受け取った情報の使用と、ほかのアプリへの転送は、限定的使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に従います。
5. アクセスの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
6. 問い合わせ：このリポジトリの Issues

# Privacy Policy (video-studio rclone)

1. This app is used only by its owner to copy the owner's own Google Drive files between the owner's Drive, the owner's computer and the owner's cloud workspace. It has no other users.
2. It reads and writes only files in the Google Drive of the account that granted access.
3. Data is never sold, shared with third parties, or used for advertising. It is stored only on the owner's computer and cloud workspace.
4. The use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.
5. Access can be revoked at any time from "Third-party apps & services" in the Google Account.
6. Contact: Issues of this repository.
