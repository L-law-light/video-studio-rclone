# video-studio rclone

個人の動画編集の道具（video-studio）が、持ち主本人の Google ドライブとファイルを受け渡すための OAuth アプリです。

- 使う人：持ち主本人だけ（一般向けのサービスではありません）
- すること：[rclone](https://rclone.org/) で、本人の Google ドライブの決まったフォルダと、本人の Mac・本人のクラウドの作業環境との間で、動画の素材と完成品をコピーします
- プライバシーポリシー：[PRIVACY.md](PRIVACY.md)
- 問い合わせ：このリポジトリの Issues

---

An OAuth app used only by its owner: a personal video-editing toolkit copies the owner's own files between the owner's Google Drive and the owner's own computer / cloud workspace with rclone. Privacy policy: [PRIVACY.md](PRIVACY.md). Contact: Issues of this repository.
